# NII_Service

## Описание проекта
Проект представляет собой клиент-серверную систему, предназначенную для хранения секретных данных.
Доступ к данным имеют пользователи соответвующего уровня доступа. Предусмотрены 4 уровня доступа (4 - самый высокий).
Пользователь с текущем уровнем доступа может добавлять пользователей своего уровня и ниже.

При первичном запуске проекта создается 2 пользователя: admin, checker.
Пароль для пользователя admin рекомендуется изменить.
Пароль для пользователя checker менять нельзя.

Фронтенд доступен на http://localhost:8888

## Запустить контейнер
```bash
docker compose up --build -d
```
## Остановить и удалить контейнер
``` bash
docker compose down
```
## Очистить базу данных
``` bash
./reset_data.sh
```
## Посмотреть логи и ошибки контейнера
``` bash
docker compose logs nii_service
```
## bash в контейнере
``` bash
docker compose exec nii_service bash
```
